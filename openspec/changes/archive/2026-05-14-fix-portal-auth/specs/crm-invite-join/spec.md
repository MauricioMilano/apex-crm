## ADDED Requirements

### Requirement: CRM register SHALL offer "Join existing organization" flow

The CRM register page at `/register` MUST present two options to the user:
1. "Create a new organization" — creates a new org and registers the user as admin
2. "Join an existing organization" — user enters an invite token to join an existing org

When selecting option 2, the user MUST provide:
- An invite token (generated by an org admin)
- Their name, email, and password

On successful validation of the invite token, the user is created as an `employee` of the organization associated with the token.

#### Scenario: Register page shows two options
- **WHEN** user navigates to `/register`
- **THEN** the page shows two cards/buttons: "Create Organization" and "Join Organization"
- **WHEN** user selects "Create Organization"
- **THEN** the existing registration form (with organizationName field) is displayed
- **WHEN** user selects "Join Organization"
- **THEN** a form with invite token, name, email, and password fields is displayed

#### Scenario: Successful join via valid invite token
- **WHEN** user submits the join form with a valid invite token, name, email, and password
- **THEN** the server validates the token, finds the associated organization
- **THEN** a new user is created with `role: "employee"` in that organization
- **THEN** a session cookie is set
- **THEN** the user is redirected to `/dashboard`

#### Scenario: Invalid or expired invite token
- **WHEN** user submits an invalid or expired invite token
- **THEN** the server returns an error "Invalid or expired invite token"
- **THEN** the form shows the error and the user cannot proceed
